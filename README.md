## Where NBA International Players Came From: Analysis of Opening Night Rosters from 2026-27 and 2025-26 seasons

This project analyzes international player representation on NBA opening night rosters across the 2025-26 and 2026-27 seasons. Using Python and Pandas, the notebook processes roster data to examine trends by country, NBA club, and continent.

## Project Overview

The analysis processes primary datasets containing opening night rosters and aggregates player counts to evaluate year-over-year changes:
* **Country Analysis:** Tracks the number of players per country, calculating absolute and percentage changes between seasons.
* **Team Analysis:** Identifies which NBA franchises feature the highest concentration of international players and measures roster shifts.
* **Continent Mapping:** Maps countries to their respective continents to observe macro-level regional representation in the league.

## Datasets Required

To run this notebook, ensure the following CSV files are in the same directory:
* `Opening night rosters - 202627.csv` ([Source](https://pr.nba.com/international-players-2026-27-nba-rosters/))
* `Opening night rosters - 202526.csv` ([Source](https://pr.nba.com/international-players-2025-26-nba-rosters/))

*Note: The script also exports processed data into `nba_countries_for_map.csv` for visualization tools like Datawrapper.

## Running the analysis yourself

You can run the analysis yourself. To do so, you'll need the following installed on your computer:

* **Python 3.11+**
* **Pandas** (Data manipulation, aggregation, and merging)
